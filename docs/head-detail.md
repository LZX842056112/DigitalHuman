# 视频头部细节

当前人物使用独立的三维头部资产。全身照片仍决定身体和灰色卫衣。头部来自视频第 4 秒的清晰原始帧。

安装和构建入口：

```powershell
Set-Location D:\Projects\3d\DigitalHuman
.\scripts\setup_head.ps1
.\scripts\build_head.ps1
.\start.ps1
```

先完成原人物的身体构建，再执行头部构建。构建前停止交互会话。GPU 锁会阻止同时执行两个任务。完整安装入口 `setup.ps1` 也安装头部依赖。独立安装不会替换 Torch 或语音环境。

`configs/head_models.json` 固定代码、模型版本和 SHA-256。头部构建严格加载 560 个推理张量。训练损失网络不进入运行流程。视频先裁剪、分割并跟踪，再生成 180255 个头部高斯点。FLAME 与 SMPL-X 的共同顶点确定头部位置和比例。运行时用头顶锚点跟随身体姿态。声音表情系数驱动面部和下颌。

头部使用与身体一致的相机射线。头部神经渲染尺寸为 512 × 512。结果只按实际头部区域缩小，不放大低分辨率图像。缩放下限可避免超过原生细节范围。全身画布可选 512、768 或 1024。

资产保存到人物目录的 `.heads/<版本>/head.safetensors`。`head.json` 记录张量校验值、身体状态校验值和源帧校验值。`state.json` 和原身体张量保持不变。只有完整写入后才切换描述文件。重启时自动加载头部资产。构建失败保留旧描述文件，并在 `outputs/head-detail-<时间>/report.json` 保存原因。

正面参考不包含完整后脑。头部增强在 55 至 80 度之间逐步减弱。更大的角度使用原身体模型的估计头部。当前衣领和头发附近仍有残影。该方案尚未通过高仿真外观验收。

实际构建图和重载记录：`outputs/head-detail-20261028-014552/`。该检查包含正面、斜侧、张嘴、估计背面、步行、挥手和位置变化。它不替代十分钟性能测试。旧版帧率不表示新版帧率。

实时声音使用网页中的原生音频播放器。用户已确认能够听到回答。音色相似度和浏览器实际音画偏差仍需对照检查。

视频使用本机 VP8 质量配置。初始码率为 4、6 或 8 Mbps，分别对应 512、768 或 1024。该配置只用于本机连接。编码器保留纹理，并限制强压缩。音频沿用原 Opus 编码器。人物清晰度还受原始素材和重建模型限制。

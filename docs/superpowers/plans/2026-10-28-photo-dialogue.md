# 照片对话数字人实施计划

用户已确认：一张照片；口型、眨眼、表情和轻微头部动作；文字和麦克风智能对话；视频只提取声音；表情和声音自动表达情感；按句准备后播放，优先自然效果。

## 实施顺序

1. 保存包含未提交文件的源码快照。保留原照片、视频、旧模型和既有输出。
2. 验证 Ditto 官方 PyTorch v0.4 HuBERT 照片动画和 Fun-CosyVoice3-0.5B-2512 情感声音。新模型使用独立 Python 环境，固定源码、权重和依赖，显卡推理串行执行。
3. 保留 CPU Qwen2.5-3B、CPU INT8 faster-whisper、WebRTC 和原生音频播放。回答携带文字及 neutral/happy/sad/angry 情感，同一句的声音和动画使用相同情感。无效情感使用 neutral。
4. 照片原比例合成；只解码视频音轨，生成约六秒声音参考。声音确认不再要求转写文本。照片与声音缓存独立，旧人物以首张身体照片和原视频迁移后重新准备。
5. 新链路可用后，删除三维重建、头像候选、骨架、动作、相机、ARKit 转换以及旧模型依赖、配置、脚本和专用测试。默认安装不再下载旧权重。
6. 界面仅保留照片、声音参考、准备、文字/麦克风对话、音量和打断。保留人物导入/删除、任务、会话接口；导入改为 photo + voice_video，删除头像候选和三维控制接口。
7. 按句使用同一音频时钟播放。待播队列不超过两句，帧解码有界。打断清除音视频队列，失效任务不能发布旧结果。

## 检查

模型基线：真实照片生成至少十秒；参考声音合成带情感的新句子。测试仅解码音轨、来源独立、迁移与重启、情感映射、音频与画面时序、队列与打断。完整有效测试和前端编译。至少十轮对话，十分钟稳定性检查。记录等待、生成/播放速度、显存和音画差，音画差目标不超过150毫秒。外观、声音身份和情感自然度由人工试看试听验收。

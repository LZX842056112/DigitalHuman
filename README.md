## 运行

在系统 PowerShell 中执行以下命令。

```powershell
Set-Location D:\Projects\3d\DigitalHuman
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\doctor.ps1
powershell -ExecutionPolicy Bypass -File .\start.ps1
powershell -ExecutionPolicy Bypass -File .\build_avatar.ps1 -Stage all
```

打开 `http://localhost:7860`。先检查参考录音和文字。构建通过后，点击“启动交互”。拖动画面可旋转视角。使用滚轮可缩放。动作按钮提供站立、步行和挥手。

首次加载会预热渲染器。加载完成后，系统才建立媒体连接。命令行构建的任务状态也会自动刷新到浏览器。

输入文字可发起对话。授权麦克风后，按住“说话”按钮可录音。松开按钮可提交录音。“打断”会清除当前播放队列和表情。单次录音上限为 30 秒。

停止服务：

```powershell
powershell -ExecutionPolicy Bypass -File .\stop.ps1
```

停止脚本会等待各进程退出并释放端口，单个服务最多等待 20 秒。超时后保留管理记录，便于重试。脚本通过进程编号和启动时间确认归属。

`start.ps1 -StudioOnly` 只启动 WSL 工作室接口。它用于导入素材和检查构建状态。它不会启动声音、口型和对话服务。

`setup.ps1 -EnvironmentOnly` 只安装 Python 和 CUDA 依赖。它不会完成模型下载或启动服务。

命令行完整构建和验证在人物包就绪后运行十轮、至少十分钟的 WebRTC 验收。报告保存在 `outputs/acceptance/`。使用 `build_avatar.ps1 -SkipAcceptance` 可单独执行构建。外观和声音身份仍需人工对照。

`build_avatar.ps1 -Stage reconstruct` 单独验证三维重建、状态重载和表情映射。此阶段不调用声音服务。人物包须完成后续声音验证，才能启动完整交互。

## 素材与人物包

人物选择框旁提供“删除人物”按钮。确认后会删除所选人物在项目内的素材副本、模型和参考声音。桌面原始文件和共享模型会保留。构建、加载或交互期间禁止删除。删除默认人物后，脚本选择另一个人物；删除最后一个人物后清除默认编号。历史任务和验收记录保留。

默认素材角色见 `configs/subject.yaml`。主照片为 `psc.png`。辅助照片只提取面部裁剪图。它们的服装不会替换主照片中的服装。如果检测出多个相近大小的面部，脚本会跳过该照片。主面部面积至少为第二个检测框的四倍时，脚本可排除较小误检。检测结果保存在 `processed/faces/photo_checks.json`。裁剪图的校验值和原编号决定跟踪缓存，新增照片会触发重新跟踪。

原视频先复制到人物目录。复制后，脚本检查 SHA-256。解码器提取 16 kHz 单声道音频。面部候选帧保留源帧编号。跟踪器只处理选中的实际裁剪图。漏检不会改变其他帧的编号。

Multi-HMR 拟合 SMPL-X 体型。BiRefNet 提取身体前景。LHMPP-700M 生成高斯状态和神经渲染特征。头部校准只更新局部高斯特征和位置。身体与网络参数保持冻结。

人物状态使用 JSON 和 safetensors。每次保存写入新的 `.states/` 版本。写入完成后，脚本原子替换 `state.json`。保存失败不会覆盖上一个完整状态。

重建采用 BF16。保存和加载时均检查张量数值。NaN 或无穷值会阻止后续流程。全身阶段完成后，脚本保存素材、权重版本和状态校验值。面部校准失败后，只有这些记录仍一致，才能复用全身状态。面部校准按保留帧的验证误差选择步骤；没有改善时，结果不予采用。

人物包包含相机、骨架、体型、图像特征、动作特征、表情转换矩阵和声音参考。构建结束后释放图像编码器和重建网络的显存。运行时直接加载人物状态、蒙皮器和神经渲染器。

推理阶段缓存固定蒙皮权重和中性关节。表情影响的权重仍实时计算。体型或头部高斯位置变化会使相应缓存失效。骨架变换使用 CUDA 图。面部优化保留梯度路径，不使用推理图。

头部校准只更新固定蒙皮区域内的高斯特征和位置。此阶段可缓存不变的蒙皮权重。非头部区域保持冻结。缓存的值和头部位置梯度均有回归检查。CUDA 图保留其输入张量，防止其他缓存刷新后丢失输入。

## 本地服务

- 工作室：`127.0.0.1:7860`。
- llama.cpp：`127.0.0.1:8081`。使用 Qwen2.5-3B Q4_K_M，CPU 推理。
- GPT-SoVITS：`127.0.0.1:9880`。使用 v2ProPlus，CPU 推理。
- LAM-A2E：`127.0.0.1:9881`。输出 30 FPS 的 ARKit 52 维系数，CPU 推理。
- faster-whisper：在工作室进程中使用 small 模型。计算类型为 CPU INT8。

声音配置使用 `s1v3.ckpt` 和 `v2Pro/s2Gv2ProPlus.pth`。参考 WAV、原话和语言随人物包保存。验证会合成一条新的测试句。它不会用源视频播放代替声音合成。

表情转换使用发布方的 ARKit 顶点位移、SMPL-X/FLAME 顶点映射，以及当前渲染器的实际 FLAME 表情基。下颌基由有限差分计算。转换不复制系数下标。

WebRTC 不配置外部 STUN 或 TURN。音频时钟驱动表情。播放队列最多保留两个待播片段。打断会废弃旧轮次结果。服务只绑定本机地址。
